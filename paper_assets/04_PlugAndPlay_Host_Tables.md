# Plug-and-play host comparisons

Each row compares a host with its paired QGIN variant using the same source sampling plan and host loss. Differences are candidate minus host; positive values favor QGIN for retrieval scores, and negative values favor QGIN for distance/error endpoints. Each Δ is followed by its paired 95% confidence interval. Absolute scores and their confidence intervals are in the [main tables](03_Main_Benchmark_Tables.md).

All scores are percentages except Dis@1 in meters. Brackets give percentile 95% confidence intervals from 2,000 place-cluster bootstrap draws. DenseUAV has 777 test places, each with three query heights, and an 18,198-image gallery with six positives per query. SUES-200 has 80 test places, four heights and 50 frames per height; its 200-image gallery includes one positive per query. Every frame, height and condition of a sampled place stays together. Two-seed means average the fixed seed-42 and seed-43 endpoints within each common resampling replicate. Worst-height R@1 is the minimum over height-specific means, recomputed in each replicate, then averaged over the two seeds.

CorrMean6 averages all six degraded conditions. NonSnowMean5 averages Fog, Blur, Gamma, ExposureClip and Posterize4. AP follows the evaluated dataset protocols: trapezoidal AP for DenseUAV and standard AP (reciprocal rank for one positive) for SUES-200. SDM@3 uses the official exponentially weighted coordinate-distance score. SUES-200 has no GPS in the evaluation manifest, so its SDM and meter-based endpoints are marked —. Cross-domain checkpoints are evaluated directly without target updates.

The machine-readable source is [paired_host_gains.csv](summary_csv/paired_host_gains.csv).
